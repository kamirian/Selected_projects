KIVI: 2-Bit KV-Cache Quantization

CMSC 723 — Graduate NLP

Training-free 2-bit quantization of the KV cache for LLaMA-2 7B and 13B. Implements the full KIVI pipeline — per-channel key quantization, per-token value quantization, residual buffer — as a drop-in replacement for LLaMA attention. Evaluated on CNN/DM, GSM8K, and CoQA.
